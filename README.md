# C言語を使った、コンピューターサイエンス学習

C言語を使って、メモリ管理、ポインタ、コンピュータの内部構造の理解などを学ぶため

## ソースコードが実行するまで。
ソースコードを実行するまでにいくつかの手順がある。
まず前提として、コンピュータはバイナリ(0と1)でしか理解できない。

## コンパイル
- コンバイラというプログラムでソースコードを受け取り、マシンコード(0と1)を生成する。
- コンバイラは、ソースコードをマシンコードに変換するプログラム。
- ソースコードをコンピュータに直接理解できるためにコンパイルをするためのプログラム。

## コマンド実行後の流れ
- makeコマンドでコンパイラにアクセスする(make hello)
- 作りたいプログラムを入力(./hello)を入力し、helloを呼び出す。
- 自分のコンピュータの中にあるhelloのファイルを検索
- hello.cファイルにある、「hello, world」が出力

## なぜ、再度コンパイルをしなければならないのか？
- C言語がそういうものだから。
- 当時は非常に慎重だった。パフォーマンス優先。
- 今はコンパイルを主導しなくても自動でやってくれるが、これらの過程がどのようになっているのかを理解するため
- 変更したソースコードなどは古いファイルに反映されないから、新しいソースコードや変更したソースコードをコンピュータに伝えるため。

## データ型
- bool 真偽値 真または偽 true false
- char 1文字 aや1のような単一
- double 浮動小数点数。小数点以下の何桁かを伴う実数。
- float doubleよりもさらに多くの桁数を持つことができる。
- int C言語では３２ビット(40億を超える数まで扱える)
- long 64ビット
- string 文字列 複数の文字として扱う

変数にint型の整数の場合、C言語ではこれを正数に変換して小数点以下を全て切り捨ててしまう。
計算は正しく行われるが、浮動小数点数や小数点以下の数字を正数に収めることができないため、
小数点以下の数字すべて失われてしまう。
整数部分の整数にしか収めることができない。
